# Windows Penetration Testing & Metasploit Lab

## Overview

Performed hands-on Windows penetration testing exercises in a controlled lab environment using the Metasploit Framework.

## Assessment

- Conducted SMB and NetBIOS enumeration to identify available services and potential attack vectors.
- Used Metasploit to exploit vulnerable Windows services and establish Meterpreter sessions.
- Performed post-exploitation enumeration within compromised Windows systems.
- Practiced Windows privilege escalation techniques in a controlled lab environment.
- Worked with NTLM hashes and credential access techniques during post-exploitation exercises.
- Applied penetration testing methodologies from enumeration through exploitation and post-exploitation.

## Key Techniques

- SMB & NetBIOS Enumeration
- Metasploit Framework
- Meterpreter
- Windows Privilege Escalation
- NTLM Hashes
- Post-Exploitation
- Service Enumeration

## Key Takeaways

- Service enumeration helps identify potential attack vectors.
- Metasploit can be used throughout different stages of a penetration test.
- Meterpreter provides capabilities for post-exploitation activities.
- Windows privilege escalation requires systematic enumeration and validation.
