# Network Defense Project Using Security Onion

## Overview

Led a team-based Network Defense project focused on detecting a simulated sensitive data exfiltration attempt using Security Onion and network monitoring tools.

## Project Activities

- Led the team, distributed tasks, and monitored progress throughout the project.
- Explained the practical scenario and presented the project findings.
- Used Zeek, Wazuh, tcpdump, and Kibana to analyze network activity and identify the data exfiltration attempt.
- Collaborated with the team to investigate the scenario and communicate the findings.
- Presented the project within a 15-minute presentation and achieved a full team grade.

## Tools Used

- Security Onion
- Zeek
- Wazuh
- tcpdump
- Kibana

## Key Skills

- Network Security
- Network Forensics
- Security Monitoring
- Network Traffic Analysis
- Team Leadership
- Incident Investigation

## Key Takeaways

- Network monitoring tools can help identify suspicious activity and potential data exfiltration.
- Correlating network activity across multiple security tools improves investigation accuracy.
- Effective teamwork and task distribution are important when investigating security incidents.
